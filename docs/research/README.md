# Research

Technical research for Novsay. Each file covers a topic area with questions and
answers. New research may also be generated per-UC during Phase 1 of the build
workflow.

## Topics

- [Web content fetching](web-content.md) — fetching, extracting, validating chapter content
- [Audio generation](audio-generation.md) — TTS providers, audio preparation
- [Audio playback](audio-playback.md) — playback, background audio, controls
- [Data storage](data-storage.md) — storing transcripts, audio, user data
- [Listening progress](listening-progress.md) — tracking and restoring play position
- [Preparation and recovery](preparation-and-recovery.md) — request states, failure handling
- [Authentication](authentication.md) — login, accounts, access control
- [Stack and deployment](stack-and-deployment.md) — runtime, hosting, CI/CD, monitoring

## Question status

Each question in these files carries a status:

- `open` — not started
- `researching` — in progress
- `answered` — answer written in this file
- `decided → DEC-NNN` — answer led to a decision record in `docs/decisions/`
